# Junli Liu GitHub Pages Homepage

这是 Junli Liu 的 GitHub Pages 个人主页静态站点。

## 文件结构

```text
github-pages-modern/
├── index.html
├── styles.css
└── assets/
    ├── profile.jpg
    ├── aerialvg.jpg
    ├── openfly.jpg
    ├── freegaussian.jpg
    ├── profile-placeholder.svg
    └── work-*.svg
```

## 如何使用

1. 在 GitHub 创建仓库：`Ideal-ljl.github.io`
2. 把本目录下的所有文件上传到仓库根目录
3. 打开 `https://Ideal-ljl.github.io/`

## 本地预览

直接用浏览器打开 `index.html` 即可。

也可以运行：

```bash
python3 -m http.server 8080
```

然后打开：

```text
http://localhost:8080
```
